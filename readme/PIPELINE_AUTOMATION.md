# Pipeline Automation - What's New

## Summary

Created **automated train & evaluate pipeline** that:
- ✅ Trains for **200 episodes by default**
- ✅ **Automatically finds** the latest run (no manual path needed)
- ✅ **Evaluates on test set** automatically
- ✅ **Shows results summary** at the end
- ✅ **One command** to do everything

## New Files Created

### 1. `train_and_evaluate.py` (Python Version)
**Most flexible option**


## How It Works

### Python Script Flow
```
train_and_evaluate.py
├── Parse arguments (--episodes 200, --eval-episodes 30, etc)
├── Run training
│   └── subprocess.run("python3 train_chronological.py ...")
├── Get latest run
│   └── get_latest_run() finds newest output_data/fake_ppo_run_*
├── Run evaluation
│   └── subprocess.run("python3 evaluate_model.py --run-dir <latest>")
├── Print results summary
│   └── Read and display evaluation_summary.txt
└── Done ✅
```

### Shell Script Flow
```
run_full_pipeline.sh [EPISODES] [EVAL_EPISODES]
├── Activate venv
├── Run training (default: 200 episodes)
│   └── python3 train_chronological.py
├── Find latest run
│   └── ls -td output_data/*ppo_run_* | head -1
├── Run evaluation (default: 30 episodes)
│   └── python3 evaluate_model.py --run-dir <latest>
└── Print results paths
```

## Advanced Usage

### Monitor Training on Dashboard
While pipeline runs:
```bash
# Terminal 1: Run pipeline
python3 train_and_evaluate.py

# Terminal 2: (while above is running)
streamlit run dashboard.py
```

Open `http://localhost:8501` to see live updates

### Custom Training Hyperparameters
For advanced control, use original scripts:
```bash
# Step 1: Custom training
python3 train_chronological.py \
    --episodes 200 \
    --learning-rate 0.001 \
    --batch-size 32 \
    --epsilon-decay 0.995

# Step 2: Evaluate on latest
python3 evaluate_model.py \
    --run-dir $(ls -td output_data/*ppo_run_* | head -1) \
    --eval-episodes 30
```

## Troubleshooting

### Issue: "ModuleNotFoundError"
```bash
source .venv/bin/activate
python3 train_and_evaluate.py
```

### Issue: "Permission denied" on shell script
```bash
chmod +x run_full_pipeline.sh
./run_full_pipeline.sh
```

### Issue: "No training run found"
Make sure training completes (look for `policy_net.pth` in output directory)
